The three woff2 files are modified subsets of Dot Matrix Regular, Bold and
Bold Tall, cut to Latin basic plus common punctuation and converted with
pyftsubset. Recorded upstream SHA-256 values for Regular and Bold Tall:

  230b56470879bf6eebeed29127d22594d923a9a93fd598a25044da976914a596  Dot Matrix Regular.ttf
  318c30a32b6365234902803104db833b683c0d93f1fe678a45148d9c5b3249b4  Dot Matrix Bold Tall.ttf

These are modified subsets: their glyph coverage and file format differ from
upstream. The upstream project declares no Reserved Font Names. Keep this notice
and OFL.txt with the files.
